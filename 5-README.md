# BOUNDARY
A local-model-assisted threat-modeling desk. The published static UI does not run a model or scan any target. Use only for systems you own or are authorized to assess.

Use the same `server.mjs` companion bridge included in PATCHROOM, backed by the linked MiMo GGUF in recent llama.cpp. The bridge listens only on loopback and both tools share it. Model and license caveats are in PATCHROOM's README.

Source post: https://x.com/0x0SojalSec/status/2103298971032777123?s=46 . Model card: https://huggingface.co/0xSojalSec/Abliterated-MiMo-V2.6-Distill-Qwen-9B-GGUF-MLX .
